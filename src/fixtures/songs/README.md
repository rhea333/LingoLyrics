# Test songs

One song for the PoC, in Japanese. Its 20 lines also serve as the 20 R2 test
lines.

| File                            | Content                              | Rights                                                                                                          |
| ------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `ja/poc-test-song.songmap.json` | 20 lines, 4 s apart, starting at 2 s | **Placeholder.** The text and timings are stand-ins until the team-written lyrics arrive.                       |
| `ja/poc-test-song.wav`          | not yet added                        | Will be generated by a script in phase 4 (tones plus a click at each line start), so the team owns it outright. |

## Rules

This repo is public and MIT-licensed. Do **not** add commercial lyrics or
audio. Every song map must record where its lyrics and audio come from in
`rights`. While content is pending, use the license `PLACEHOLDER`.

## Replacing the placeholder lyrics

1. Replace each `text` with one lyric line, keeping 20 lines if possible.
2. Set `rights.lyrics` to `{ "license": "MIT", "source": "written by <names> for LingoLyrics" }`.
3. Adjust `startMs`/`endMs` if the lines need different lengths.
4. Run `npm run validate:maps` from `src/`.
